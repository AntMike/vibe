# Нотатки зі встановлення 📝

## Системні вимоги

Windows: версія `8` або новіша.

macOS: версія `13.3` або новіша.

Linux: протестовано на `ubuntu-22.04+`

Обладнання:
Особливих вимог немає. Використання ресурсів можна налаштувати в розширених параметрах головного вікна.

Наразі прослуховування аудіофайлу в `Linux` не підтримується

Крім того, перед запуском може знадобитися задати цю змінну середовища

```console
export WEBKIT_DISABLE_COMPOSITING_MODE=1
```

## Налаштування підсумків за допомогою Ollama

1. Встановіть Ollama

Завантажте й встановіть Ollama з https://ollama.com.

2. Встановіть модель

Після встановлення налаштуйте модель для підсумків. Наприклад, можна встановити `llama3.1`, виконавши в терміналі таку команду:

```console
ollama run llama3.1
```

3. Увімкніть підсумки

Коли модель встановлено, відкрийте застосунок Ollama. Перейдіть до `Більше параметрів` й увімкніть `Підсумувати` безпосередньо перед кроком транскрипції. Решту налаштувань можна залишити за замовчуванням.

_Обов’язково виконайте `Run check`, щоб переконатися, що все працює_

Це все! Підсумки тепер працюватимуть в Ollama.

## Стабільні часові мітки (субтитри / фільми)

Vibe має режим стабільних часових міток для точнішого таймінгу субтитрів у довгих записах.

1. Відкрийте `Більше параметрів`.
2. Увімкніть `Стабільні мітки часу`.
3. Якщо буде запропоновано, завантажте модель VAD.

Примітки:

- Цей режим орієнтований на якість і зазвичай приблизно в `4x` повільніший за звичайну транскрипцію.
- Найкраще підходить для створення субтитрів і таймінгу транскрипцій фільмів/відео.
- Модель VAD за замовчуванням: `ggml-silero-v6.2.0.bin`
- Першоджерело моделі: `https://huggingface.co/ggml-org/whisper-vad`

## Переклад англійською

Переклад англійською працює лише з моделями Whisper `small`, `medium` та `large`. З Whisper `large-v3-turbo` він не працює.

Якщо вам потрібен переклад, завантажте підтримувану модель зі [сторінки моделей](/vibe/docs#models).

## Ручне встановлення 🛠️

`MacOS Apple silicon`: встановіть файл `aarch64.dmg` зі [сторінки релізів](https://github.com/thewh1teagle/vibe/releases) **Не забудьте один раз клацнути правою кнопкою та відкрити з Програм**

`MacOS Intel`: встановіть файл `x64.dmg` зі [сторінки релізів](https://github.com/thewh1teagle/vibe/releases) **Не забудьте один раз клацнути правою кнопкою та відкрити з Програм**

`Windows`: встановіть файл `.exe` зі [сторінки релізів](https://github.com/thewh1teagle/vibe/releases)

`Linux`: встановіть `.deb` зі [сторінки релізів](https://github.com/thewh1teagle/vibe/releases) (користувачі `Arch` можуть скористатися [debtap](https://aur.archlinux.org/packages/debtap))

_Усі моделі доступні для ручного встановлення. Див. [Готові моделі](https://github.com/thewh1teagle/vibe/releases/tag/v0.0.1)_

## Офлайн-налаштування 💾

Офлайн-встановлення Vibe просте: відкрийте застосунок, скасуйте завантаження та перейдіть до розділу `Налаштувати` в налаштуваннях.

_Усі моделі доступні для ручного встановлення. Див. налаштування або [Готові моделі](https://github.com/thewh1teagle/vibe/releases/tag/v0.0.1)_

## Швидша транскрипція на macOS (у 2–3 рази) 🌟

1. Завантажте відповідний вашій моделі `.mlcmodelc.zip` з https://huggingface.co/ggerganov/whisper.cpp/tree/main

- напр., `ggml-medium-encoder.mlmodelc.zip` відповідає `ggml-medium-encoder.bin`

2. Відкрийте шлях до моделей в налаштуваннях Vibe
3. Перетягніть файл `.mlcmodel.c` до теки моделей, щоб він лежав поруч із файлом `.bin`
4. Транскрибуйте файл: при першому використанні моделі це триватиме довше, бо модель компілюється. Кожного наступного разу буде швидше.

## Помилка `msvc140.dll` не знайдено ❌

Завантажте й встановіть [vc_redist.x64.exe](https://aka.ms/vs/17/release/vc_redist.x64.exe)

## Спеціальне посилання для завантаження моделей у Vibe

Ви можете додати на свої сайти посилання, щоб користувачі могли легко завантажувати ваші моделі зі сайту просто у Vibe.

URL має бути такого вигляду

```
vibe://download/?url=https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-tiny.bin?download=true
```

## Використання на сервері Linux

Щоб використовувати Vibe на сервері Linux, потрібно встановити віртуальний дисплей

```console
sudo apt-get install xvfb -y
Xvfb :1 -screen 0 1024x768x24 &
export DISPLAY=1

wget https://github.com/thewh1teagle/vibe/releases/download/v0.0.1/ggml-medium.bin
wget https://github.com/thewh1teagle/vibe/raw/main/server/fixtures/single.wav
vibe --model ggml-medium.bin --file single.wav
```
