## New

- 🧠 Додано розширений параметр для автоматичного вивантаження неактивних моделей транскрибування та звільнення RAM/VRAM; встановіть 0, щоб моделі залишалися завантаженими
- ⏱️ Активні вивантаження, VAD, діаризацію та тривалі транскрибування захищено від вивантаження через простій – таймаут починається лише після завершення обробки
- 🌍 Додано переклади параметра неактивності моделей для всіх підтримуваних мов

## Improved

- ⚡ Покращено повторне використання моделей: Sona пропускає перезавантаження вже завантаженої відповідної моделі
- 🔄 Sona оновлено до v0.3.5 із відстеженням батьківського процесу в Windows і надійним очищенням дочірніх процесів

## Fixed

- 🪟 Виправлено ситуацію, коли Vibe і Sona залишалися відкритими після виходу в Windows, через що пам’ять GPU могла лишатися зайнятою, а повторний запуск був неможливий
