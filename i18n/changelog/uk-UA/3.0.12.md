- 🛡️ Кнопка транскрибування вимикається, якщо не вибрано модель, і показує підказку
- ⬇️ Посилання на завантаження моделей переміщено нагору налаштувань для зручнішого доступу

## Improved

- 📋 Sona тепер повідомляє версію та хеш коміту під час запуску

- 🔧 Виправлено збій завантаження моделі для користувачів із не-ASCII іменами в Windows
- 🖥️ Плавний перехід на CPU, якщо драйвери Vulkan GPU відсутні
- 🔍 Зрозуміліші повідомлення про помилки, коли sona аварійно завершується під час завантаження моделі
