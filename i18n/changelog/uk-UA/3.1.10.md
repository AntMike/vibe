## Fixed

- 🧩 **Немає середовища Vulkan — не проблема** — ПК з Windows без завантажувача Vulkan (без `vulkan-1.dll`, типово для комп’ютерів без драйвера GPU) узагалі не міг запустити рушій транскрибування. Тепер рушій відкриває завантажувач під час виконання й просто працює на CPU, якщо його немає. Upstream: ggml-org/ggml#1614
- 🎯 **Правильні транскрипції на графіці AMD зі старішими драйверами** — на деяких GPU AMD із драйвером Windows 2020 року (помічено на інтегрованому Radeon ноутбука Ryzen) GPU видавав нісенітницю: одинокий «!» або випадкові символи, тоді як CPU був правий. Драйвер залишає GPU неокласифікованим у рушії, і ядро уваги тоді просило ширину підгрупи, яку апаратне забезпечення не може виконати. Sona 0.6.5 просить її лише там, де драйвер може її надати, і GPU знову транскрибує правильно, у кілька разів швидше за CPU. Виправлення для upstream запропоновано до ggml (ggml-org/ggml#1619)
